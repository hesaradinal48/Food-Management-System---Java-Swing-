🍔 Food Delivery System

A simple Food Delivery Management System developed using Java Swing and MySQL.
The application provides basic CRUD functionality for managing food items, customers, sellers, and orders.

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Java JDK
IntelliJ IDEA
MySQL Server
MySQL Connector/J
Setup
Clone the repository.
Open the project in IntelliJ IDEA.
Create the required database in MySQL.
Update the database connection details in the project.
Add the MySQL JDBC driver.
Run the application.
📌 Project Overview

This project demonstrates how to build a desktop-based CRUD application using Java Swing, with MySQL used for persistent data storage.

The main purpose of the system is to provide a simple way to manage food delivery-related data through a graphical user interface.
